# 내 주식 사이트, 처음부터 이해하기

React와 Next.js를 한 번도 써보지 않은 프로젝트 주인을 위한 설명서입니다. 코드를 외우기보다 **“어떤 일이 생기면 어디를 보면 되는가”**를 익히는 것이 목표입니다.

2026-09-23 로컬 소스 기준입니다. 실제 운영 서버, Supabase의 현재 데이터·설정, GitHub 작업 성공 여부는 확인하지 않았습니다. 아래의 “구현됨”은 해당 코드가 있다는 뜻입니다.

파일을 열었는데 `#`, `|` 같은 기호가 그대로 보이면 Markdown 원문을 보고 있는 것입니다. 편집기의 **Markdown 미리보기** 또는 GitHub의 파일 화면에서 읽으면 제목과 표로 표시됩니다. 그림은 별도 프로그램 없이 읽을 수 있는 문자 그림으로 넣었습니다. 링크를 누르면 관련 소스로 이동합니다.

## 지금 세 문장만 기억한다면

1. **React는 화면 조각을 만들고, Next.js는 그 조각을 URL별 페이지와 서버 기능으로 엮습니다.**
2. **Supabase는 데이터를 보관하고 로그인을 처리합니다.** 화면에서 바로 Supabase로 요청하는 경우도 있습니다.
3. **주가 수집 Python은 별도로 돌아갑니다.** 웹사이트를 켰다고 과거 주가가 자동으로 채워지지는 않습니다.

문서의 코드 경로는 별도 설명이 없으면 `source/stock-web/` 안을 기준으로 합니다. `src/app/page.tsx`라고 하면 실제 위치는 `source/stock-web/src/app/page.tsx`입니다.

## 문서를 믿는 방법

일반 개념과 이 프로젝트의 구현을 구분했습니다. 예컨대 TanStack Query는 설치되어 있지만 현재 화면 조회는 주로 `useEffect`와 Supabase 호출로 작성되어 있습니다. 설치된 도구 목록이 곧 실제 동작 설명은 아닙니다.

기능이 달라지면 해당 문서도 함께 고치세요. 코드와 설명이 다르면 코드 및 SQL 변경 이력을 먼저 확인하고, 운영 환경은 별도로 확인해야 합니다.
