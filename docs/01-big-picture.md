# 1. 전체 그림: 이 사이트는 어디에서 돌아갈까?

## 하나의 사이트, 네 개의 작업 장소

주식 사이트를 “자료실이 있는 가게”라고 생각해 봅시다. 손님이 보는 진열대가 화면이라면, 자료실은 데이터베이스이고, 매일 자료를 채우는 직원은 수집 프로그램입니다.

```text
① 사용자 브라우저                   ② Next.js 서버
   화면 표시, 클릭 처리 ──페이지 요청──→ 페이지 준비
   차트, 검색, 별 버튼  ──API 요청────→ 외부 시세 조회 ──→ 네이버
          │                                │
          └──────── 데이터 읽기/쓰기 ───────┤
                                           ↓
                                  ③ Supabase
                                  주가·글·회원 데이터 저장
                                  로그인, 접근 권한, 변경 알림
                                           ↑
                                  ④ Python 수집 프로그램
                                  GitHub Actions가 예약 실행
                                  외부 자료를 받아 DB에 저장
```

①은 방문자 컴퓨터에서, ②는 개발 중에는 내 컴퓨터에서 실행됩니다. 배포하면 ②는 호스팅 서버에서 실행됩니다. ③은 연결한 Supabase 프로젝트, ④는 설정된 GitHub Actions 실행 환경에서 돌아갑니다. Python을 직접 실행할 수도 있습니다.

**웹 서버가 정상이어도 수집이 멈추면 주가 자료는 오래될 수 있습니다.** 반대로 웹 서버를 꺼도 GitHub의 예약 수집은 독립적으로 실행될 수 있습니다.

## 이름이 많은 이유

| 이름 | 쉬운 뜻 | 이 프로젝트에서 맡은 일 |
|---|---|---|
| HTML | 화면의 내용과 뼈대 | 제목, 입력칸, 버튼 |
| CSS | 화면의 모양 규칙 | 색, 간격, 모바일 배치 |
| JavaScript | 동작을 표현하는 언어 | 클릭했을 때 탭 전환 |
| TypeScript | JavaScript에 데이터 형태 검사를 더한 언어 | 종목 코드가 문자열인지 등 검사 |
| React | 화면 조각을 조립하는 도구 | 검색창, 즐겨찾기 버튼, 토론 카드 |
| Next.js | React에 주소·서버·빌드 체계를 더한 틀 | `/stocks/005930` 페이지, 시세 API |
| Node.js | 브라우저 밖에서 JavaScript를 실행하는 프로그램 | 내 컴퓨터의 Next.js 서버 실행 |
| npm | 필요한 외부 프로그램 묶음을 설치하고 명령을 실행하는 도구 | `npm ci`, `npm run dev` |
| Tailwind CSS | 작은 스타일 이름을 조합하는 도구 | `text-2xl`, `px-2`, `flex` |
| Supabase | DB·로그인 등을 제공하는 서비스 | PostgreSQL DB, Google 로그인 연동, Realtime |
| Lightweight Charts | 차트를 그리는 라이브러리 | 캔들 및 보조지표 표시 |
| GitHub Actions | 예약 또는 코드 변경에 맞춰 작업하는 자동 실행기 | 주가 수집, DB 구조 변경 적용 |

`package.json`에 Next.js **16.2.3**, React **19.2.4**가 지정되어 있습니다. 인터넷 예제와 코드 모양이 다르면 먼저 버전을 확인하세요. “최신 버전으로 전부 바꾸기”는 설명서를 읽기 위한 준비 작업이 아닙니다.

## 현재 무엇을 할 수 있나?

| 구분 | 소스에서 확인한 내용 |
|---|---|
| 홈 | 관심 종목 주가 카드와 관심 종목 토론 피드 |
| 검색 | 종목 자동완성, 종목·토론글 검색 |
| 종목 상세 | 차트, 일·주·월봉, 보조지표, 차트 메모, 기업정보, 토론 |
| 토론 | 글, 댓글·답글, 좋아요·싫어요, 글 상세 주소 |
| 계정 | Google 로그인, 첫 로그인 닉네임 설정 |
| 관심 종목 | 비로그인 시 브라우저 저장, 로그인 시 DB 저장 |
| 랭킹 | 거래량·거래대금, 등락, 기업가치, 토론, 유동물량, 섹터 |
| 현재가 | 네이버 자료를 주기적으로 요청하는 코드가 있음 |
| 준비 중 | 종목 상세의 시세·뉴스·공시·수급현황 탭은 안내 화면 |
| NXT | 수집·통합 계산 코드는 있으나 NXT 단독 선택 버튼은 비활성화 |
| 결제·가격 예측 | Stripe 환경 변수나 예측 테이블 등 흔적은 있으나 완성된 서비스 흐름은 확인되지 않음 |

여기서 “현재가”는 거래소가 매 체결을 밀어주는 완전한 실시간 스트림을 뜻하지 않습니다. 이 앱은 외부 자료를 일정 간격으로 다시 요청합니다. 코드가 있다는 사실만으로 외부 API의 현재 정상 동작이나 데이터 정확성이 보장되지는 않습니다.

## 파일, 실행 중인 화면, 저장 데이터는 서로 다르다

```text
코드 파일 수정 → 실행 중인 앱이 새 코드를 반영 → 화면 모양/동작 변화
버튼 클릭     → 실행 중인 화면의 상태 변화  → 필요하면 DB에 저장
SQL 적용      → DB 구조/권한 변화           → 화면 코드와 별개로 영향
```

화면 문구를 바꾸는 일과 DB의 글을 삭제하는 일은 서로 다른 작업입니다. `npm run dev`를 다시 켠다고 DB가 초기화되지 않습니다. 브라우저 새로고침을 해도 DB에 저장된 글은 남습니다.

**이해 확인:** “사이트는 열리는데 어제 주가만 보인다”면 어디를 먼저 볼까요? 화면 코드뿐 아니라 수집 실행 기록과 DB의 마지막 저장 날짜를 봅니다.
