# 작업 기록 색인

`docs/history/`는 세션마다 남긴 작업 기록의 폴더다. 무엇을 왜 했는지, 사용자가 무엇을 정했고 무엇을 해 보고 버렸는지가 들어 있다. 이 색인은 그 기록을 주제별로 묶어, 맡은 일과 같은 주제의 지난 작업만 골라 읽게 한다.

읽는 법: 맡은 일의 주제 표를 열어 최근 줄부터 읽는다. 지금 동작은 코드와 폴더 안내가 정본이고, 기록은 '왜 그렇게 됐나'를 볼 때 읽는다.

파일 이름은 `YYMMDD_주제-작업기록.md`(한국 날짜)다. 2026-11-22 전에는 세션별 기록을 남기지 않았다. 그때의 작업은 커밋 로그에서 주제별로 묶어 줄의 기록 칸에 `기록 없음`과 커밋 해시를 적었고, 그 줄이 곧 그 작업의 기록이다(커밋 메시지에 적힌 것만 옮겼다. 이유와 사용자 말은 남아 있지 않다). 자세한 것은 `git show <해시>`.

새 기록을 쓰면 아래 주제 표에 줄 하나를 올리고(한 기록이 여러 주제를 다루면 주제마다 줄을 따로) '날짜순'에도 올린다. `python3 docs/check-index.py`가 이 폴더의 모든 기록이 여기 링크돼 있는지 본다.

관련 문서: [프로젝트 색인](../INDEX.md), [결정과 일하는 방식](../decisions.md), [문서 안내](../CLAUDE.md).
