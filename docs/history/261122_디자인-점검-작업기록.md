# 디자인 점검: PC·모바일을 돌아보고 손봄

2026-11-22(한국 시각), 맥 세션. 사용자 요청: "에고브라우저에서 여기저기 돌아다니면서 테스트해보고, 디자인 좀 개선해봐. pc/mo 둘 다 봐야해".

관련: [app 안내](../../src/app/CLAUDE.md), [components 안내](../../src/components/CLAUDE.md).

## 본 곳

운영(`stock-web-lilac.vercel.app`)을 ego-browser로 1440×900(PC)과 390×844(모바일, 터치)에서 열었다: 홈, 랭킹(거래량·등락률·섹터·가치), 토론방, 종목 상세(`/stocks/005930`), 모바일 드로어, 라이트·다크 테마. 로컬에는 `.env.local`이 없어 개발 서버를 띄우지 않았고, 고친 것은 `design-qa` 브랜치를 올려 Vercel 미리보기에서 같은 화면을 다시 봤다.

## 찾은 것과 고친 것

| 찾은 것 | 고친 것 |
| --- | --- |
| 본문 글꼴이 Times(명조)였다. `globals.css`의 `@theme`에 `--font-sans: var(--font-sans)`로 자기 자신을 가리켜 값이 무효가 됐다 | `--font-sans`를 Pretendard → Geist → OS 한글 글꼴 순으로 바꿨다. Pretendard는 `layout.tsx`에서 jsDelivr의 dynamic subset 스타일시트로 읽는다. 숫자는 `tnum`(고정폭) |
| `<html lang="en">` | `lang="ko"` |
| PC 헤더: 사이드바 위 칸이 비었고 검색창(52px)이 56px 헤더를 꽉 채워 위에 붙어 보였다 | 헤더 왼쪽 `w-64`에 브랜드("주식 앱", 모바일 드로어 머리와 같은 모양), `StockSearch`에 `compact`(헤더용 낮은 입력창). 모바일 하단바는 기본 크기(py-3) |
| 랭킹 행의 보조 '등락'이 회색이라 오르내림이 안 보였다 | `RankingTableRow.secondary`에 `tone`을 더하고 `lib/rankings.ts`가 `toneFromChange`로 채운다. 상승 빨강, 하락 파랑 |
| 강조색이 파랑(사이드바·로그인)과 보라(토론 로그인 버튼, 댓글, 홈 링크, 차트 메모 버튼)로 섞였다 | 보라(`violet-*`)를 파랑(`blue-*`)으로 |
| 모바일 좌우 여백 8px | 12px(`px-3`). 차트 폭을 너무 줄이지 않으려고 16px까지는 넓히지 않았다 |

## 확인

- `sh tool/check.sh` 통과.
- 미리보기에서 PC 랭킹·종목 상세(다크·라이트), 모바일 홈·종목 상세·등락률·드로어를 다시 찍어 봤다. 모바일 가로 넘침 없음(`scrollWidth` 390).
- 로그인한 화면(글쓰기, 즐겨찾기 목록이 찬 홈)은 보지 못했다(확인 못 함).

## 남은 일

- 종목 상세 탭 줄이 모바일에서 오른쪽 끝(수급현황)이 잘린다. 가로 스크롤은 되지만 더 있다는 표시가 없다.
- 차트의 'NXT 준비 중'처럼 흐린 글씨는 라이트 테마에서 대비가 낮다.
- 라이트 테마의 `--sidebar-primary`는 검정이라 브랜드 아이콘·선택 메뉴가 검정이고, 다크는 파랑이다. 의도인지 확인 못 함.
